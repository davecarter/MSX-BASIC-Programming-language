# Lesson 01 — First program and saving

Objectives:
- Type a short BASIC program
- Run it and save it to disk

Steps:
1. Open your MSX or emulator and go to the BASIC prompt.
2. Type this program (or load examples/guess_number.bas):

```
10 CLS
20 PRINT "HELLO MSX BASIC"
30 INPUT "What is your name? "; N$
40 PRINT "HELLO "; N$
50 END
```

3. RUN to execute.
4. SAVE "A:HELLO.BAS" to persist your program (ensure A: is writable/mounted in the emulator).
