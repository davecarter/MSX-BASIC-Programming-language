Examples included

This folder contains small, runnable MSX BASIC programs to help learners practice and experiment.

Files:
- guess_number.bas — a number-guessing game (Spanish/English prompts).
- graphics_demo.bas — simple moving character using LOCATE and PRINT.
- sound_demo.bas — brief music example using PLAY (emulator support varies).
- file_io_demo.bas — demonstrates SAVE and LOAD of BASIC programs.

How to run these examples
1. Open an MSX emulator (openMSX, blueMSX) or a real MSX.
2. To run a .BAS file, either paste the file contents into the BASIC prompt, or mount the file/disk image and use LOAD "A:FILENAME.BAS" then RUN.
3. For emulators: use the file-transfer or mount options to copy files into a virtual disk image or cartridge.

Notes
- Some emulators vary in exact support for PLAY and sound; consult the emulator documentation if a sound example does not play.
- These examples are intentionally short — modify them to experiment and learn.
